# 0003. No outside contributions

- Status: Accepted
- Date: 2026-10-21
- Issue: none. The owner stated this in chat.

## Context

The repository is public, and its process files were copied from projects that accept outside work. This one is a personal tool.

## Decision

Issues and pull requests from anyone other than the owner are not accepted. The Issue, branch, and PR steps stay as the owner's own process, including work done with an agent.

## Consequences

README and the issue-template note say so. There is no `CONTRIBUTING.md`. A rule in `.cursor/rules/contributions.mdc` stops an agent from inviting or carrying out outside work.
